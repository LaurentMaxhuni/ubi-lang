export record Signal {
    radius: int,
    duration: int,
    label: string,
}

export fn signal(energy: int) -> Signal {
    // A typed value for your interface.
    Signal {
        radius: 40 + energy,
        duration: 24 - energy / 5,
        label: mood(energy),
    }
}

From this repository

Install the Ubi CLI with Rust and Cargo.

cargo install --path .

Write your first Ubi function ＋
export fn main() -> string {
    "Hello from Ubi!"
}

Save as main.ubi. With Node.js installed, run ubi run main.ubi.

Build a web interface ＋

Put HTML, CSS, and JavaScript in web/. Import compiled functions from /__ubi/modules/main.mjs, then run ubi dev main.ubi.
