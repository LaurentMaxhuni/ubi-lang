# Ubi V1 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement owned tasks and independent review. Continuous execution is authorized by the user.

**Goal:** Run shared Ubi applications on web, CLI, desktop, and mobile with checked async effects, persistence, packaging, and usable tooling.

**Architecture:** Keep Rust compiler and independent AST interpreter. Emit ESM; share Ubi application rules across thin hosts. Package Electron desktop and Capacitor mobile projects with explicit native prerequisites.

**Tech Stack:** Rust, JavaScript ESM, Node, browser DOM, Electron, Capacitor.

**Spec:** SPEC.md sections 21-22, alongside existing language contracts.

## Global Constraints

- Async calls require immediate await; arrows remain pure and synchronous.
- Host capabilities/effects cannot escape; budgets survive await.
- Preserve unrelated files and existing state on failed writes/corrupt reads.
- Support web, cli, desktop, mobile; document runtime floors and SDK checks.
- Separate implementation from conformance authoring and final review.
- Commit each meaningful completed change; do not publish or invent sign-off.

## Review Focus

- Nested await in branches/loops/arguments retains order and early Result propagation.
- Async aliases/callbacks/imports cannot hide effects or bypass budgets.
- Cancellation/malformed responses/rejections produce specified distinct outcomes.
- Existing files, symlink escapes, and failed persistence remain safe.
- Packaged URLs/assets and narrow-screen/keyboard flows work outside the dev server.

### Task 3: Developer loop

### Task 4: Release verification and documentation

**Files:** README.md, PLAN.md, DECISIONS.md, platform status docs, CI/release scripts.

- Baseline: 151 existing tests pass outside Windows sandbox. Sandboxed child compiler processes cannot canonicalize temporary roots (Access denied); use reviewed escalation for test execution.
